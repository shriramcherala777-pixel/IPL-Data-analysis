# IPL Data Analysis

A data analysis project exploring IPL match and ball-by-ball data using Python, Pandas, and Matplotlib.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Analysis Performed

- Most successful IPL teams
- Top run scorers
- Top wicket takers
- Toss impact on match results
- Extras distribution
- Death-over performance
- Run distribution and match statistics

## Dataset

The project uses IPL match-level and ball-by-ball delivery data.

The dataset is included in `IPL_dataset.zip`.

## How to Run

1. Download or clone the repository.
2. Extract `IPL_dataset.zip`.
3. Place `matches.csv` and `deliveries.csv` in the same directory as `IplDataAnalysis.py`.
4. Run:

```bash
python IplDataAnalysis.py
